# Skill Routing

Luôn đọc file này trước khi chọn skill.

## Frontend Angular
Nếu task liên quan đến Angular, component, page, form, route, RxJS, signal, UI, npm build frontend:
- Ưu tiên skill: <tên skill frontend đã install>
- Nếu có nhiều skill frontend: chọn skill có description gần nhất với task

## Backend Node.js
Nếu task liên quan đến API, controller, service, middleware, validation, auth:
- Ưu tiên skill: <tên skill backend đã install>

## Database
Nếu task liên quan đến PostgreSQL, schema, migration, static data, category key value:
- Ưu tiên skill: <tên skill database đã install>

## DevOps
Nếu task liên quan đến Docker, Vercel, CI/CD, env, build, deploy:
- Ưu tiên skill: <tên skill devops đã install>

## SDLC
Nếu task liên quan đến Epic, User Story, Task, Unit of Work, Plan:
- Ưu tiên skill: <tên skill sdlc đã install>

## Nguyên tắc chọn skill
1. Không tự ý sửa/move skill đã install.
2. Chỉ đọc skill phù hợp với ngữ cảnh.
3. Nếu task thuộc nhiều nhóm, chọn skill chính trước, sau đó dùng skill phụ.
4. Nếu không chắc, đọc description của các skill trước khi chọn.
5. Không dùng tất cả skill cùng lúc.





# Skill selection policy

AUTO:
- Use when user does not specify skills.

PREFERRED:
- Use when user mentions a domain.

FORCED:
- Use only explicitly requested skills.
