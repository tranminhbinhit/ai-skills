# ui-ux-pro-max

Comprehensive design guide for web, mobile, and desktop applications. Contains 67 styles, 161 color palettes, 57 font pairings, 99 UX guidelines, and 25 chart types across 22 technology stacks.

## When to Use

- Design intelligence and UX guidance
- Palette, typography, and layout recommendations
- Stack-specific UI guidance for React, Angular, Vue, Tailwind, shadcn/ui, SwiftUI, Flutter, and more
- UX heuristics for mobile, accessibility, and interaction patterns

## Workflow

1. Clarify the product context and target users.
2. Generate a design system direction with style, color, typography, and layout guidance.
3. Add UX recommendations and anti-patterns to avoid.
4. Recommend implementation-friendly patterns for the requested stack.

## Usage Notes

- Prefer this skill for design intelligence tasks.
- Use the bundled child skills for specialized tasks such as branding, banners, slides, or UI styling.
- On Windows, use `python` instead of `python3` when running the bundled search scripts.
