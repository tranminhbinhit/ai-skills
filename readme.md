## 🏗️ Architecture

**Skills-first, steering-minimal approach:**
- **Skills** (`.kiro/skills/`) = Domain knowledge, organized by domain (web/, backend/, database/, mobile/)
- **Steering** (`.kiro/steering/core/`) = Only 2 cross-cutting workflow files

Before restructure: 90+ files in steering (unmanageable)  
After restructure: 2 steering files, ~100 files in skills (clean)

Read more: [`document/skills-vs-steering-architecture.md`](document/skills-vs-steering-architecture.md)

## 🚀 Getting Started

### For New Users
1. **Install hot skills:** Follow [`document/quick-install-guide.md`](document/quick-install-guide.md) (5 min)
2. **Learn AI-DLC:** Read [`.kiro/plans/QUICKSTART.md`](.kiro/plans/QUICKSTART.md)
3. **Test skills:** Try example prompts from quick install guide
4. **Explore roadmap:** See what's coming in [`document/skills-roadmap.md`](document/skills-roadmap.md)

### For Contributors
1. **Understand architecture:** Read [`document/skills-vs-steering-architecture.md`](document/skills-vs-steering-architecture.md)
2. **Review roadmap:** Pick a skill from [`document/skills-roadmap.md`](document/skills-roadmap.md)
3. **Follow structure:** Use skill template from roadmap
4. **Submit PR:** Add to appropriate domain folder (web/, backend/, etc.)
